# Reviewer Response Matrix

## Required fields

| Field | Purpose |
| --- | --- |
| ID | Stable editor or reviewer comment identifier |
| Original comment | Verbatim wording |
| Concern | Underlying issue |
| Severity | Blocking, major, moderate, or minor |
| Action | Revise, analyse, clarify, evidence, relocate, shorten, or disagree |
| Dependencies | Data, code, source, co-author, editor, or none |
| Proposed revision | Planned change before implementation |
| Completed change | Verified change after implementation |
| Location | Verified page, section, table, figure, or line |
| Response text | Polished author reply |
| Status | Not started, planned, completed, verified, or blocked |

## Response language

### Agreement

“We appreciate this concern. We have revised [specific element] to [specific purpose]. The change appears in [verified location].”

### Clarification

“We agree that the earlier presentation did not make [issue] sufficiently clear. We now clarify [content] in [verified location].”

### Additional analysis

“To address this concern, we conducted [actual analysis]. The results [accurate summary] and are reported in [verified location].”

### Respectful disagreement

“We appreciate the rationale for this suggestion. We have not adopted [request] because [evidence-based reason]. To address the underlying concern, we instead [actual clarification or analysis].”

Use future tense and “proposed” labels until the change exists.

## Cross-comment reconciliation

- Merge duplicate work while responding separately to each reviewer.
- Identify contradictory requests and explain the chosen resolution.
- Update the abstract, methods, results, discussion, tables, appendices, and response letter consistently.
- Keep reviewer-specific confidential content out of other responses.

## Completion gate

A row is verified only when:

1. the action exists in the current manuscript or analysis
2. the location is accurate
3. the response describes the action faithfully
4. all dependent sections are consistent
5. no unsupported claim or unverified citation was introduced
