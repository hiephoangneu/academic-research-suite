# Reviewer Response Manager

## Establish the revision record

1. Read the decision letter, editor comments, every reviewer report, the current manuscript, supplementary files, and journal instructions.
2. Preserve each comment verbatim and assign a stable identifier such as `E1`, `R1.1`, or `R2.4`.
3. Split compound comments into traceable subparts without changing their meaning.
4. Identify cross-reviewer overlaps, contradictions, dependencies, and requests that affect multiple manuscript sections.
5. Verify current journal resubmission requirements from authoritative sources.

## Classify each comment

Assign:

- concern type: theory, literature, method, results, interpretation, reporting, citation, ethics, presentation, or journal compliance
- severity: blocking, major, moderate, or minor
- action: revise, analyse, clarify, provide evidence, relocate, shorten, or respectfully disagree
- dependencies: data, code, co-author decision, new source, editor clarification, or none
- status: not started, planned, completed, verified, or blocked

## Draft the response

Use this structure:

1. **Comment:** Preserve the reviewer wording.
2. **Response:** Answer the concern directly and respectfully.
3. **Change made:** Describe only changes actually completed.
4. **Location:** Give verified page, section, table, figure, or line references.
5. **Evidence:** Add methodological or substantive support when needed.

When the manuscript has not yet been edited, label the item **Proposed revision** and avoid past tense.

## Manage disagreement

1. Acknowledge the underlying concern.
2. State the manuscript's position precisely.
3. Provide evidence from theory, design, data, journal scope, or methodological standards.
4. Offer a clarifying or boundary-setting revision when it improves the manuscript.
5. Avoid defensive language and unsupported appeals to authority.

## Verify completion

Before marking a comment completed:

- confirm the revised text or analysis exists
- confirm all affected sections were updated
- confirm tables, figures, appendices, citations, hypotheses, and terminology remain consistent
- confirm the response accurately describes the revision
- confirm every location reference is real
- confirm no reviewer comment was omitted

## Integrity rules

- Never fabricate page numbers, line numbers, analyses, citations, editor approval, or co-author agreement.
- Never claim that code was rerun or results changed without evidence.
- Do not accept a reviewer request that would introduce a methodological error without explaining the problem and proposing a sound alternative.
- Keep confidential editor comments separate from author-facing material.

## Output

Return the response matrix first, followed by the polished response letter and a prioritised revision checklist. If the user authorises document editing, update the manuscript and reverify the matrix against the edited file.
