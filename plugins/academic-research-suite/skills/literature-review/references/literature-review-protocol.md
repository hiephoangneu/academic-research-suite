## Select the review mode

| Mode | Best fit | Minimum discipline | Typical output |
| --- | --- | --- | --- |
| Integrative theory-building | Explain a phenomenon, reconcile theories, or construct a framework | Transparent scope, plural search terms, theory and evidence appraisal, contradiction analysis | Theory synthesis and conceptual framework |
| Systematic | Answer a tightly bounded question with reproducible coverage | Protocol, explicit eligibility criteria, complete search strings, database records, screening log, quality appraisal | Reproducible evidence synthesis |
| Scoping | Map a broad, fragmented, or emerging field | Explicit scope, transparent search and screening, concept and evidence mapping | Field map, taxonomy, and research agenda |
| Critical | Reassess assumptions or dominant explanations | Deliberate theory sampling, transparent critical criteria, rival explanations | Reframed debate or alternative theory |
| Rapid | Provide time-bounded decision support | Predeclared shortcuts, transparent omissions, focused validation | Bounded synthesis with explicit limitations |

Do not present PRISMA as a method for conducting every literature review. Use the relevant PRISMA guidance to report a systematic or scoping review when applicable. PRISMA-S concerns transparent reporting of literature searches and does not by itself establish search quality.

Authoritative reporting resources, to be checked for current versions when used:

- [PRISMA 2020 statement](https://www.prisma-statement.org/prisma-2020)
- [PRISMA 2020 checklist](https://www.prisma-statement.org/prisma-2020-checklist)
- [PRISMA-S search-reporting extension](https://www.prisma-statement.org/prisma-search)
- [PRISMA-ScR scoping-review extension](https://www.prisma-statement.org/scoping)
- [Cochrane guidance on searching and selecting studies](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04), for applicable systematic-review designs

## Scope statement

Record:

- Review purpose and audience
- Phenomenon and research question
- Discipline and adjacent disciplines
- Unit and level of analysis
- Population, market, industry, institution, or country boundaries
- Publication types and languages
- Date horizon and justification
- Focal constructs and excluded near-neighbours
- Review mode and reasons
- Intended outputs

## Search architecture

Create separate concept blocks before combining them:

| Block | Contents |
| --- | --- |
| Phenomenon | Core term, synonyms, acronyms, legacy terms |
| Constructs | Formal names, dimensions, validated labels, near-neighbours |
| Theories | Theory names, mechanisms, assumptions, major critiques |
| Relationships | Antecedent, outcome, mediation, moderation, configuration, dynamics |
| Context | Sector, country, institution, population, level, period |
| Method | Optional design, estimator, measurement, or review-method terms |

Search broad enough to discover alternative explanations, then narrow using declared eligibility rules. Test exact phrases and controlled vocabulary where the platform supports them. Preserve each final query exactly as run.

## Search log

| Field | Required record |
| --- | --- |
| Source | Database, index, repository, publisher, registry, or web source |
| Platform | Host platform when distinct from the database |
| Date | Date and time zone searched |
| Query | Exact syntax, fields, truncation, and operators |
| Filters | Years, language, document type, subject area, and access rules |
| Results | Count returned and count retained at each stage when available |
| Chaining | Seed paper and backward or forward path |
| Notes | Query changes, access limitations, deduplication, and anomalies |

For systematic work, preserve deduplication, title and abstract screening, full-text screening, exclusions with reasons, and reviewer-resolution records. Recommend an information specialist's review of high-stakes or publication-bound search strategies when feasible.

## Coverage status

Report this status before substantive conclusions:

| Field | Status to report |
| --- | --- |
| Search coverage | Sources and platforms searched, exact last-search date, and unavailable databases |
| Access level | Counts read in full text, abstract only, metadata only, or secondary report |
| Workflow stage | Protocol, search, deduplication, screening, extraction, appraisal, or synthesis completed |
| Selection | Records retrieved, deduplicated, screened, excluded, and included when available |
| Verification | Sources and claims still unresolved |
| Completion boundary | Work that remains before the review can support publication claims |

## Source verification record

For every cited source, record:

- Full bibliographic identity and DOI or stable URL
- Source used to verify metadata
- Accessed text: full paper, accepted manuscript, abstract only, or secondary report
- Exact claim supported
- Evidence type and design
- Sample, context, time, and level of analysis
- Construct definitions and measures
- Direction, magnitude, uncertainty, and robustness where reported
- Causal or associational reach
- Retraction, correction, or expression-of-concern status when relevant
- Limitations and transferability to the proposed framework

## Foundational-theory map

| Field | Question |
| --- | --- |
| Theory | What is the theory's verified name and foundational source? |
| Core problem | What phenomenon was it developed to explain? |
| Mechanism | Through what process does the predicted effect occur? |
| Assumptions | What must be true for the mechanism to operate? |
| Level and time | At what level and over what time scale does it operate? |
| Constructs | Which constructs belong to the theory rather than being later additions? |
| Predictions | What direction, form, or configuration is predicted? |
| Boundary conditions | When should the prediction weaken, reverse, or fail? |
| Evidence | What supports, challenges, or revises the theory? |
| Framework role | Why is it necessary for this research question? |

Prefer a theory because its mechanism fits the phenomenon, not because it is fashionable or frequently cited. A framework may integrate multiple theories only when their levels, assumptions, and mechanisms are compatible or the tensions are made explicit.

## Evidence and contradiction matrix

| Study | Theory | Constructs and roles | Design and context | Finding | Inferential strength | Boundary or contradiction | Framework implication |
| --- | --- | --- | --- | --- | --- | --- | --- |

After extraction, synthesise by mechanism and relationship. Investigate whether conflicting results follow from measurement, design, context, time, sample, estimator, or genuinely competing theoretical predictions.

## Research-gap test

A defensible gap should answer all of these:

1. What does the field currently believe?
2. What specific contradiction, missing mechanism, boundary, level mismatch, or identification problem remains?
3. Why does resolving it change theoretical or practical understanding?
4. What evidence shows that the gap is current rather than assumed?
5. Can the proposed design actually resolve or narrow it?

Rank gaps as high, medium, or low consequence. A setting gap is high consequence only when the setting changes mechanisms, institutions, incentives, constraints, measurement, or external validity.

## Framework audit

For each construct and arrow, verify:

- Construct definition and dimensionality are stable enough for the proposed role.
- Predictor and outcome are not aliases or overlapping operationalisations.
- The arrow has a named mechanism rather than only empirical precedent.
- The cited theory actually entails the relationship.
- Evidence is not solely cross-sectional when temporal or causal claims are made.
- Mediators preserve temporal order and are not alternative outcomes.
- Moderators have a clear interaction mechanism and range of relevance.
- Controls are not colliders, mediators, or consequences of treatment.
- Unit and level of analysis are aligned.
- Context is a justified boundary condition, not decorative background.
- Rival direction, reciprocal effect, nonlinearity, and configuration have been considered.
- The final model is more informative than a simpler alternative.

## Mandatory failure checks

Do not:

- Invent or complete partial citation metadata from memory.
- Use snippets as evidence for detailed claims.
- Equate citation count with validity or theoretical fit.
- Treat all Q1 or highly ranked papers as equally credible.
- Hide inaccessible full texts or uncertain interpretations.
- Claim saturation, exhaustiveness, or systematic coverage without records.
- Count papers as a substitute for appraising evidence.
- Build hypotheses by attaching one citation to each arrow.
- Convert mixed findings into a false consensus.
- Select only supportive studies after seeing the desired model.
- Report a framework as established when it is exploratory.

## Completion gate

Before delivery, confirm that:

1. The review mode matches the question and available search access.
2. Foundational theories and current frontier studies are both represented.
3. Every material external claim has a verified source or an explicit verification note.
4. Contradictory and null evidence is visible.
5. Each framework link has mechanism, theory, evidence, boundary, and inferential calibration.
6. Search and access limitations are stated prominently.
7. The reference list contains no source that was not verified to the level claimed.
