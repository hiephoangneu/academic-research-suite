# Pre-Submission Quality Checklist

> Run ALL checks before submitting to any journal. Every item must pass (✅).

---

## A. Content Quality (16 items)

### Title and Abstract
- [ ] Title is 10-15 words, specific, and keyword-rich
- [ ] No abbreviations in title (unless universally known)
- [ ] Abstract is 150-250 words with all 5 components
- [ ] No citations in abstract
- [ ] Keywords are 4-7 terms, relevant and searchable

### Introduction
- [ ] Opens with a compelling hook (not a definition or cliche)
- [ ] Research gap is explicitly and clearly stated
- [ ] Purpose statement uses precise language
- [ ] RQs/hypotheses are numbered and clearly stated
- [ ] Contributions (theoretical, practical, methodological) are articulated

### Literature Review
- [ ] Organized thematically (not chronologically)
- [ ] Synthesizes (not merely summarizes) prior research
- [ ] Theoretical framework is clearly presented and justified
- [ ] Hypotheses are logically derived from the literature
- [ ] Gap flows naturally from the review

### Methodology
- [ ] Design is stated and justified
- [ ] Sample size is justified (power analysis for quantitative)
- [ ] All instruments have validity and reliability evidence
- [ ] Procedure is detailed enough for replication
- [ ] Analysis methods are specified for each RQ/hypothesis
- [ ] Ethics approval is stated with reference number

### Results
- [ ] Organized by RQ/hypothesis
- [ ] No interpretation in Results section
- [ ] Exact statistics reported with effect sizes
- [ ] All tables/figures referenced in text
- [ ] Hypothesis support/non-support explicitly stated

### Discussion
- [ ] Each finding is compared with prior literature
- [ ] Theoretical framework used for interpretation
- [ ] Theoretical and practical implications discussed
- [ ] Limitations are specific (not generic)
- [ ] Future research suggestions are actionable

### Conclusion
- [ ] No new findings or citations introduced
- [ ] Concise (300-500 words)
- [ ] Ends with a forward-looking statement

---

## B. Language and Style (14 items)

- [ ] No em dashes (—) anywhere in manuscript
- [ ] No double hyphens (--) used as dash substitutes
- [ ] En dashes (–) used ONLY for number ranges
- [ ] Active voice predominant
- [ ] No first-person singular ("I")
- [ ] Consistent verb tense per section
- [ ] No sentences exceeding 35 words
- [ ] No single-sentence paragraphs
- [ ] All paragraphs have topic sentence + evidence + transition
- [ ] No contractions (don't, can't, won't, it's)
- [ ] No colloquial language or slang
- [ ] No rhetorical questions
- [ ] No exclamation marks
- [ ] Spelling convention consistent (American OR British)

---

## C. Citations and References (8 items)

- [ ] All in-text citations appear in reference list
- [ ] All references are cited in text (no orphans)
- [ ] Reference format matches target journal (APA 7th default)
- [ ] DOIs included for all available entries
- [ ] 40%+ references from the last 5 years
- [ ] Self-citations under 10%
- [ ] Multiple sources separated by semicolons, alphabetical
- [ ] Page numbers included for direct quotes

---

## D. Tables and Figures (6 items)

- [ ] Numbered sequentially (Table 1, Figure 1...)
- [ ] Referenced in text BEFORE they appear
- [ ] Titles are descriptive and placed above
- [ ] Notes explain abbreviations and significance markers
- [ ] No vertical lines in tables
- [ ] Figures are 300+ DPI resolution

---

## E. Formatting (8 items)

- [ ] Heading levels consistent (APA 7th: Levels 1-5)
- [ ] Double-spaced (unless journal specifies otherwise)
- [ ] 1-inch / 2.54 cm margins
- [ ] Times New Roman 12pt (or journal specification)
- [ ] Page numbers included
- [ ] Line numbers included (if required by journal)
- [ ] Running head included (if required)
- [ ] Word count within journal limits

---

## F. Ethics and Compliance (7 items)

- [ ] IRB/Ethics approval stated with reference number
- [ ] Informed consent described
- [ ] Data availability statement included
- [ ] Funding sources disclosed
- [ ] Conflicts of interest declared
- [ ] Author contributions (CRediT format)
- [ ] ORCID provided for all authors
