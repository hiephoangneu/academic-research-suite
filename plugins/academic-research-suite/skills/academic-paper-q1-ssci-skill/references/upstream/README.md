# 🎓 Academic Paper Writing Skill — Q1/SSCI Standard

## Purpose
This repository serves as a **knowledge base** for AI-assisted academic paper writing
targeting Q1/SSCI-indexed journals.

## How to Use
Connect this repo to **Perplexity AI Space** via GitHub connector.
Then use these commands in your Space:

| Command | Description |
|---------|-------------|
| `/outline [topic]` | Generate full paper outline |
| `/intro [topic + gap]` | Write Introduction section |
| `/hypothesis [variables + theory]` | Develop hypotheses with arguments |
| `/methods [design]` | Write Methodology section |
| `/discussion [findings]` | Write Discussion + Implications |
| `/abstract [summary]` | Generate structured abstract |
| `/review [text]` | Critical review of any section |
| `/polish [text]` | Improve academic writing quality |
| `/gaps [topic]` | Identify research gaps from literature |
| `/journals [topic]` | Recommend target Q1/SSCI journals |
| `/response [reviewer comment]` | Draft response to reviewer |
| `/phrases [section]` | Get academic phrase suggestions |

## Quality Standards
- All outputs follow **APA 7th Edition**
- Minimum **60-80 references** recommended
- **40%+ references** from last 5 years
- Every claim grounded in **theory + evidence**
